## Motivation Behind the Project

After spending 4 years developing [Cadaver](/portfolio/cadaver) in 2D, I decided I wanted to challenge myself by writing a 3D project. These prototypes served as my introduction to writing a 3D framework with C++ and OpenGL. 

## Key Features

In the project I implemented:

* A 3D kinematic player controller
* AABB Collisions ensuring proper collisions with platforms in 3D
* Bill board sprites which rotate on the Y-axis to always face the player using GLM
* Rather than drawing each plane on a map, I used draw call batching to group all their vertices into a single VBO and render it one draw call

## Future Plans

This project did its intended goal of helping me learn about programming a game in 3D. Once I succesfully implemented some cubes and the player controller, I realized I wanted to challenge myself and learn the math behind the graphics I was programming.
